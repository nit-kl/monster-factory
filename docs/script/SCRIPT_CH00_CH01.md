# 第1章「最後の工場」

**章の目標**：7日後に到着する勇者軍の先遣小隊（剣士・弓兵・魔法使い）を退けられる個体を作る。
**流れ**：着任 → 最初の設計と敗北 → 改良して勝つ → 弓兵 → 魔法使い → 先遣小隊の襲来 → 夜の場面。各段の間に「終業後」の短い会話。

## 1-1 着任
【工場前 → 1F製造フロア。3D工場画面へ移り、会話は立ち絵で出す】

（辺境の谷。三本ある煙突のうち、煙を上げているのは一本だけだった。）

**リゼット**：第七魔物製造工場へようこそ。副工場長のリゼット・クロウです。
**リゼット**：本社から新しい工場長が来ると聞いて……正直、閉鎖の通知を持ってこられるのかと思っていました。

▶「再建に来ました」
**リゼット**：……再建。そうですか。久しぶりに聞く言葉です。

▶「閉鎖ではありません。……たぶん」
**リゼット**：「たぶん」は、本社の方の口癖ですか。

【以下共通】

**リゼット**：現状をお伝えします。稼働している設備は三割。予算は今月で底をつきます。
**リゼット**：飼育係と整備技師は、本社に呼ばれて不在です。
**リゼット**：それから、裏山の竜には近づかないでください。寝起きが悪いので。

▶「竜？」
**リゼット**：元将軍です。今はただの、とても大きな同僚です。

（工場の奥で、何か重いものが落ちる音がした。）

**バルガス**：……おう。あんたが新しい工場長か。
**バルガス**：そこは触るなよ、まだ熱い。手の皮が持っていかれる。

（機械の下から、牛の頭を持つ巨体が這い出してきた。角に工具がひとつ引っかかっている。）

**バルガス**：設備主任のバルガスだ。……角は触るなよ。工具を引っ掛ける場所じゃねえ。
**リゼット**：今まさに引っかかっていますが。
**バルガス**：……これはわざとだ。
**バルガス**：で、本社から来たってことは、陛下のお顔を拝んだのか？

▶「帳越しに、お声だけ」
**バルガス**：そうか。昔から人前に出るのは好きじゃねえお方だった。

▶「……お元気そうでした」
**バルガス**：そりゃよかった。

【以下共通】

**バルガス**：昔、迷宮の門番をやってた頃にな。一度だけ、陛下に肩を叩かれたことがある。
**バルガス**：でけえ手だった。……それだけの話だ。

（あなたは、封書の入った鞄を握り直した。）

**オルフェン**：ほう、新しい顔じゃ。

（天井近くを、骸骨の魔導士が漂ってきた。開いた魔導書が、ひとりでに頁をめくっている。）

**オルフェン**：研究主任のオルフェン・ノクス。六百年ほど、この工場で骨を休めておる。
**リゼット**：この工場ができたのは八十年前です。
**オルフェン**：細かいことはよい。

**ポヨン**：培養と品質管理を担当しております、ポヨンです。ようこそ、工場長さん。

（巨大な半透明のスライムが、帽子を少し持ち上げた。体の中で試薬瓶がゆっくり回っている。）
（その体の奥から、小さな青いものがぽこんと飛び出した。）

**プルル**：ぷる？
**ポヨン**：あら。この子はプルル。試作体の No.000 です。
**ポヨン**：いつからこの工場にいるのか、記録が残っていないんです。私もなぜか、この子だけは放っておけなくて。

（プルルがあなたの足元まで跳ねてきて、鞄にぴたりと貼りついた。体の中の黄金の核が、ちかりと光る。）

**プルル**：ぷる……。

（あなたは慌てて鞄を引き寄せた。そのとき、封蝋の紋章がのぞいた。）

**リゼット**：……今の、王家の封蝋ですか。

▶「本社の書類です」
**リゼット**：……そうですか。

▶「気のせいでしょう」
**リゼット**：……私、目はいいんです。でも、今は聞かないでおきます。

【以下共通】

**リゼット**：本題に入ります。
**リゼット**：勇者軍の先遣小隊が、この谷に向かっています。騎士団長グレイヴ・ハルトの麾下です。
**リゼット**：剣士、弓兵、魔法使いの三名。到着は七日後。
**リゼット**：そして今、この工場には、彼らと戦える個体が一体もいません。
**バルガス**：最後の一体は、先月売っぱらったからな。修理代になった。
**リゼット**：工場長。七日で、三人を退けられる個体を作ってください。
**リゼット**：……それができなければ、再建の話もそこで終わりです。

【目標表示：「先遣小隊の到着まで あと7日」 → 2F研究フロアへ】
