# 実装状況

本編には序章と全8章、百日目の結末があります。会話の選択、材料の解禁、六種の配合、製造演出、格納庫での名付け、相談、工場内の散策を実装しています。タイトルと工場から短編「誰も押していない停止ボタン」も開始できます。

工場に個体がいれば「物語を進める」で次の場面へ移れます。通常戦・部隊戦・戦後報告は削除しました。物語上の襲撃や防衛は台本で描きます。

ブラウザに進行・配合・個体を自動保存します。旧セーブの章位置と個体の記録を引き継ぎます。

検証には npm test と npm run build を使用します。ビルド後に npm run preview を起動すると、別の端末から npm run e2e で配合・章送り・再開を確認できます。
