# 種族イラストと技構成（2026-11-15）

ユーザー承認「その方向性で現状のバトルに登場するすべてを完全に修正して」に基づく現行仕様。

## 対象と見た目

- 味方6種（鉄霊騎士、熔炉巨人、焔花竜、冥樹の番人、月晶狼、幽鐘クラゲ）と敵3種（剣士、弓兵、魔法使い）はすべて2Dイラスト。
- 味方の配合・製造・誕生・格納庫・戦闘・アイコンで同じ種族画像を使う。技を変えても画像は変わらない。
- Three.jsは背景、設備、飛び道具、粒子、光の輪などの演出に使用する。キャラクターはカメラに向くスプライト。
- 新規画像は `public/assets/monsters/*-v1.png`。熔炉巨人は既存の `furnace-colossus-concept-v1.png`、敵は既存の `public/assets/battle/*-v1.png` を使う。

## 技構成

- 配合時に種族ごとの候補4つから異なる通常技2つを選ぶ。格納庫でも無料で変更でき、個体番号・戦績・発見記録は維持される。
- 行動順は「通常技1 → 通常技2 → 種族固有技」を繰り返す。固有技は固定で、装甲・一時防御を貫通する。
- 通常技は強打、魔力弾、守勢打、再生波、侵蝕弾、生命吸収、貫通撃、疾風撃。倍率と効果は `src/data/skills.ts` が唯一の定義。
- 防御は次の被弾1回で消費し、再付与時は上書き。貫通攻撃でも消費される。毒は重複せず毎巡7ダメージ。冥樹の固有技も毒を付与する。
- 回復は最大耐久を超えない。生命吸収は実際の与ダメージ以下。敵の凍結特性は通常技による回復も止める。
- 既存の種族能力・速度差による弓兵の追撃・冷気弱点は維持。
- 敵にも2通常技＋固有技の固定順がある。弓兵の追撃は同じ技を繰り返し、技順は1巡に1つ進む。

## 計算と演出

- 決定的な戦闘シミュレーションが技ID・技名・演出種別・防御・回復などをログに記録。表示側はそのログを再生する。
- 強打は踏み込み、魔力弾は弾、守勢打は防御輪、再生波は上昇する回復輪、侵蝕弾は緑の弾、吸収は往復する光、貫通は細い投射物、疾風撃は接近と離脱。
- 6種の固有技は鉄片の雨、炉砲、火柱、根の包囲、狼の残像、共鳴輪。敵固有技は破城斬、流星連射、絶零嵐。
- 戦闘画面とログに、味方・敵それぞれが使った技名と効果を表示する。

## 保存と互換性

保存v3の `Design.moves` に2つの技IDを追加した。フィールドがない既存v2/v3セーブは種族の既定技を使い、既存の進行と戦績を保持する。未知ID・重複・別種族専用技・要素数不正は読込時に拒否。戦闘中と製造中は格納庫の技変更を受け付けない。

## 検証

- `npm run build`
- `npm test`：既存25件に加え、技の全順列×6種×3敵×3シード（648戦）の技順・HP整合、防御消費、回復・毒・凍結、保存互換、格納庫再調整を検証。
- `E2E_URL=http://127.0.0.1:5191 node test/e2e/loadouts.mjs`：ビルド後にVite previewを5191番で起動して実行。6種の画像・技選択・製造・格納庫変更・保存再開・戦闘・一時停止・結果を確認。画面は `tmp/loadouts/` に保存。
- `test/e2e/playthrough.mjs`：既存の序章から章末までの通しプレイ。

数値は試作バランス。技構成によって勝敗が変わることを意図しており、長期的なバランス調整は別途行う。
